2026-10-09 に `20260907-ai-mcp-servers-learn` から要望（ai-chat-lite #1412 の 1）。再変換すると、変わっていない `.md` と `images/*.svg` も書き直す。そのプロジェクトでは 73 ファイルが `git status` で M になり、中身は index と同じ（ハッシュ一致 ・ `git diff` は空）なのに、`git update-index --refresh` でも消えなかった。希望は、convert-encoding と同じく、書き出す前に比べて同じならファイルに触らないこと。
