2026-10-29 に利用者から要望。HTML から `.md` へのリンクがあるとき、対応する `.html` が無ければ（手書きの Markdown なら）指摘を出さない。同様に、Markdown から `.html` へのリンクがあるとき、対応する `.md` が無ければ（変換しない HTML なら）指摘を出さない。

<strong>調べた結果。</strong>いまの検査は次のとおり（`src/html2md/checks.ts`）。

- HTML 側（`testHtmlLinks`）。`.md` へのリンクは、対応する `.html` の有無を見ずに、いつも「`.md` を参照」の指摘にする。**こちらが直す対象**
- Markdown 側（`testMdLinks`）。`.html` へのリンクは、ファイルが実在すれば指摘しない。**すでに満たしている**。実在しないときの「リンク切れ」は、対応する `.md` の有無と関係なく残す

<strong>決めたこと。</strong>HTML 側だけ直す。リンク先の `.md` が実在し、同じ名前の `.html` が無いときは、指摘にしない。`.html` が実在するのに `.md` と書いたリンクは、これまでどおり指摘する（生成物を指しているため）。`.md` が実在しないときは、リンク切れとして指摘する。

- [済] `testHtmlLinks` を直した。`.md` へのリンクで、同じ名前の `.html` が無いときは指摘しない。`.md` も実在しなければ「リンク切れ」にする
- [済] テストは先に書いた。`tests/cases/md-link-unpaired`（手書きの `.md` への HTML リンクと、変換しない HTML への Markdown リンク）は、実装前に「`.md` を参照」の指摘で落ちるのを見てから直した（❌Red → ✅Green）。`md-link-paired`（`.html` が実在する `.md` への HTML リンクは、これまでどおり指摘する）は、現状を固定する保護用で、最初から通る。`md-link-missing`（実在しない `.md` はリンク切れ）は、実装と同時に書いたので、落ちるのは見ていない。全テスト成功（23 本）
