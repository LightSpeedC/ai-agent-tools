2026-09-22、共通ルールに新設された「共有ツールの置き場とPATH」（他プロジェクトから呼ばれる公開CLIは `<project>/bin/` に置き、PATHに追加するのも `bin/` フォルダのみにする）に、このプロジェクト自身が従っていなかった。現状はランチャー一式（`less`・`psls`・`check-contrast`・`check-markdown`・`check-public`・`convert-encoding`・`html2md`・`psh`・`text`、各 `.cmd` 版）がプロジェクトルート直下にあり、PATH もルート自体を指している。

マシン環境変数 PATH には `C:\work\ai-agent-tools\bin` が既に追加済みだが、`bin/` フォルダ自体・中身とも未整備の状態だった（別途誰かが先回りして PATH だけ追加していたと見られる）。

**利用者の指示で、個人用のセッション起動スクリプト（`cc.cmd`・`cx.cmd`・`n.cmd`・`nn.cmd`）も一緒に `bin/` へ移した**（本来「他プロジェクトからは呼ばれない補助スクリプト」でルール上は対象外だが、まとめて移す判断）。各ランチャーの `src/` への相対参照を1階層上に修正し、`tools/40_test/`・`tools/60_release/build-release.ps1` の参照も追随させた。

あわせて、同じ「開発者専用・公開CLIではない」区分の `build-*-cs.cmd`（C# 参照実装のビルド起動）を `tools/20_build/`、`check-contrast-ps.ps1`・`check-markdown-ps.ps1`（移行前のPowerShell参照実装）を `tools/90_misc/` へ移した（利用者の指示）。

2026-09-22 に実装完了。全体テスト・型チェック・文字コード検査（このプロジェクト自身と無関係な未追跡ファイル `cx.cmd.bak` を除く）を確認済み。

✅ **済** 2026-09-24、利用者が PATH からプロジェクトルート（`C:\work\ai-agent-tools`）を外した。レジストリ（システム PATH）を確認し、`C:\work\ai-agent-tools\bin` のみが登録され、プロジェクトルート単独の登録が無いことを確認した。

✅ **済** C# 参照実装の `.exe` 3本（`convert-encoding-cs.exe`・`html2md-cs.exe`・`text-cs.exe`、いずれも `.gitignore` 除外・未追跡）も root から共通ルールの `dist/`（ビルド出力）へ移した。`build-*-cs.cmd` の `/out:` 出力先も `dist/` に変更し、3本とも実機でビルドが通ることを確認済み。**実装時に踏んだ落とし穴**: `tests/psh/callexe.ps1`（psh のテスト用フィクスチャ）が `convert-encoding-cs.exe` を root からの固定パスで直接呼んでおり、移動直後に `tools/40_test/run-psh-tests.ts` のテストが1件落ちた。パスを `dist/` 経由に修正して解消（bun・node とも全体テスト成功を確認）。
