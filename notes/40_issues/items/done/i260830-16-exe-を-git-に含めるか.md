いまは `.gitignore` の `*.exe` で除外している。**ビルド後にサイズを測り、小さければ含める方向で再検討する**と決めていた。

現在のサイズは 35 KB 程度。含めれば clone 直後にビルドせずに使える。含めなければ差分の読めないものが履歴に残らない。

✅ **済** 2026-09-02 に**含めないことに決めた。**`.gitignore` の `*.exe` をそのまま残す。

サイズは小さいまま（実測 40 KB）だが、**変えるたびに差分の読めないものが履歴に積む。**`build.cmd` を 1 回実行すれば作れるので、clone 直後に使えないことの不便は小さい。

一度も追跡していないため、履歴の書き換えは要らない。`.gitignore` に書くだけでは追跡済みのファイルは外れないが、この exe は最初から対象外だった。
