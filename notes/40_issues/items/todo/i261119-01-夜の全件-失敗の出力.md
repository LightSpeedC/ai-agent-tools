2026-11-19 01:15 終了の夜の全件 (commit 72e9d1d) で、html2md (bun・node の 2 本) と psls (bun の 1 本) が失敗した。psls は node の回は通っているので、原因は html2md と別の可能性がある (psls はプロセスの一覧を返すため、夜に同時に動くものに左右される見込み。確かめていない)。共通ルール「落ちた理由の分からない試験は、揺れで済ませず、課題にして残す」に従い、課題にする。

## 事実 (根拠)

- **昼の単独実行は成功**: 2026-11-19 の昼 (JST)、commit 72e9d1d・作業ツリーに変更なしの状態で、`bun tools/40_test/run-psls-tests.ts` が 31 件すべて成功、`psh tools/40_test/run-tests.ps1` (html2md の golden) が 37 ケースすべて成功。psls の node 版と html2md の bun・node の別は、昼には流していない
- **夜の出力は保存されていない**: 登録 `ai-agent-tools-run-all-tests` の実行は `powershell -NoProfile -ExecutionPolicy Bypass -File ".../run-all-tests.ps1" -IfChanged` で、出力のリダイレクトが無い (`Get-ScheduledTask` の Actions で確認)。ランチャは `Write-Host` で画面に出すだけでファイルに残さない。`_run-all-times.json` は回のたびに上書きされ、時間と失敗の名前だけを残す
- **別の落ち (同じ夜、別の原因)**: run-all-tests の -Online (bun・node の 2 本) は、check-markdown 自身の単体試験の名前に当たる試験の粗さが原因で、5d41dbe で直した。html2md・psls の落ちとは関係しない

## 今ある動き (直すときに守るもの)

- 1 本ごとの出力は `invoke-with-timeout` を通して画面に流れる
- 時間切れは ⏱️ を付けて分ける
- 進み具合のファイル (`_run-all-progress`) を書く
- `-IfChanged` で、前の回から更新が無い夜は流さない
- 終了コードは、1 本でも落ちれば 1
- `_run-all-times.json` は回のたびに上書きされる
