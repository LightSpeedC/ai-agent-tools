デザインルールは `stop-color="var(--accent)"` の書き方を前提にしているが、SVG を単体ファイルに切り出すと変数が解決されず**色が失われる**。

```
<section class="ch03">
	<svg><linearGradient id="g-03-1a">
		<stop stop-color="var(--accent)"/>    ← .ch03 の定義が要る
	</linearGradient></svg>
</section>
```

`<style>` から `.chNN { --accent: … }` を読み、切り出す `svg` の祖先 `section` のクラスと突き合わせれば静的に解決できる。`@media` と JS による上書きは対象外とする。

> [!IMPORTANT]
> <strong>ルールに従って書いた HTML ほどこの問題を踏む。</strong>この html2md 自身の図はリテラルの `hsl()` で書いていたため表面化していなかった。

✅ **済** 2026-09-02 に対処。上の方針どおり実装した。**定義も既定値も無いものは書き換えずに残す**（消すと図が壊れるより、そのままのほうが気づける）。`@media` の中はブロックごと落としてから読む。

フォールバックの取り出しは括弧を数えている。`var(--x, hsl(280,78%,25%))` のように**既定値の中に括弧が入ると `[^)]*` では途中で切れて壊れる。**

あわせて、テストが `.md` しか比べていなかったのを直し、**切り出した `.svg` も exe と ps1 で突き合わせる**ようにした。既存 6 プロジェクトの SVG に `var(` を含むものは無く、影響は出ていなかった。
