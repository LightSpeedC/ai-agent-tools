次のタグは `BlockTags` に無いため、中身が地の文として 1 つに連結される。テキストは消えないが構造は失われる。

| タグ | いまの出力 | 本来あるべき形 |
|---|---|---|
| `main` `article` `aside` `header` | 5 つが 1 段落に連結される | `div` と同じ「中身を処理する」扱い |
| `dl` `dt` `dd` | `dt` と `dd` が連結される | Markdown に定義リストは無い。箇条書きか表に落とす |
| `details` `summary` | 連結される | GitHub は HTML のまま解釈するので、そのまま残す手もある |
| `hr` | 消える | `---`。ただし記号を足さない方針との兼ね合いがある |

`main` 系の 4 つは `BlockTags` に足すだけで済む。`dl` と `details` は落とし方を決める必要がある。

✅ **済** 2026-09-01 に**テキストを落とさない対処を入れた。**`hr` を除くすべてを走査の対象に加え、`dt` `dd` `summary` も個別に挙げて項目ごとの段落にした。`address` と `caption` も同時に対応した。

✅ **済** 2026-09-05 に**構造の落とし先を 3 つとも決めて実装した。**`dl` は箇条書き（`dd` は 4 字下げ）、`details` はタグのまま出す、`hr` は `---`。決着は[タグ対応仕様](../10_plan/html2md-tag-spec.md)の決着 9 にある。

✅ **済** `hr` は閉じタグを持たないため、<strong>そのまま走査に加えると後ろが丸ごと飲み込まれる。</strong>空要素として開きタグだけを切り出す分岐を `GetBlock` に入れた。
