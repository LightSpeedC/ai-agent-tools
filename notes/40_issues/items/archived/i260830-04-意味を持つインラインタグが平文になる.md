`del` `ins` `sup` `sub` `mark` `kbd` `abbr` `small` `q` `cite` `time` はタグが消えて中身のテキストだけが残る。取り消し線や上付きの区別は Markdown に出ない。

GitHub は `~~取り消し線~~` を解釈するので `del` は記法にできる。`sup` `sub` `kbd` は HTML のまま残す手もある。どこまで対応するかを決める。

✅ **済** 2026-09-01 に対処。**`del` は `~~`、GitHub で生き残るタグ（`ins` `sup` `sub` `mark` `kbd` `q`）はタグのまま残す。**`~~` も `**` と同じ前後判定を受けるため、強調と同じセンチネル方式に載せた。成立しない位置では `<del>` で出る。

<strong>どのタグが残るかは実測で決めた。</strong>11 個すべてタグで出す実装にしたあと `api.github.com/markdown` へ投げたところ、`abbr` `small` `cite` `time` の 4 個は除去された（中身のテキストは残る）。表示に効かないため平文に落とすことにした。

この対応で<strong>退避の仕組みに潜んでいた欠陥が表面化した。</strong>キーの両端が同じ制御文字だったため、`2<sup>10</sup>` のように数字が隣接すると偽のキーができ、別の退避内容に置き換わっていた。両端を別の文字にして直した。
