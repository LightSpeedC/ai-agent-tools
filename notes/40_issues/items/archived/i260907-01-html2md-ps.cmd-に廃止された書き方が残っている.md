`html2md-ps.cmd` の実行行が `powershell.exe -NoProfile …` になっている。共通ルール「実行ファイル名に `.exe` を付けない」に反する。`powershell` にする。

ai-chat-lite の指摘（#557 / #570）で調べて見つけた。<strong>この cmd は SJIS なので Grep では 0 件になり見えなかった。</strong>Grep は SJIS / UTF-16 を読めず、日本語で検索すると黙って結果から抜ける。`convert-encoding --read` で中身を読んで確認した。

このプロジェクトの SJIS ファイルは 4 件（`build.cmd` `build-convert-encoding.cmd` `build-text.cmd` `html2md-ps.cmd`）、UTF-16 は 0。`build` 系の `csc.exe` はファイルの場所を指す用途で、コマンド名の `.exe` ではないため対象外。`check-contrast.cmd`・`check-markdown.cmd`・`run-tests.cmd` は ASCII の cmd で、こちらは `powershell.exe` が残っていたため 2026-09-08 に直した（レビュー #649 low）。

✅ **済** 2026-09-07 に直した。`powershell.exe` → `powershell`。**SJIS の cmd は Edit で壊れるため、Write で全文を書き直し `convert-encoding --to cmd` で SJIS ＋ CRLF に変換した。**
