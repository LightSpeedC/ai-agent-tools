`<ul class="chapters">` の中の `span` 3 つが連結され、リンクのラベルが 1 本の長い文字列になる。

```
- [第1部 基礎編 01. PowerShell の生まれた経緯 DOS・Bash・Node.js と比較しながら、…](docs/01-背景.md)
```

要求は 3 列の表にすること。**ヘッダ行の「章」「タイトル」「内容」が HTML のどこにも無い**のが論点で、そのまま実装すると html2md 自身の「HTML に無い文言」検査に毎回引っかかる。

案は 4 つある。HTML 側にヘッダを持たせる（`data-columns`）／ HTML 側を最初から表にして CSS でカード表示にする／表にせず区切りを入れた箇条書きにする／固定文言を足して検査の対象外にする。**HTML 側を表にする案が最も筋が良い**と考えている。変換器・検査・ルールのどれにも手を入れずに済むため。

✅ **済** 2026-09-09 に、上記とは別の方向で<strong>html2md 側が chapters 構造を解釈する案（B）に決めて実装した。</strong>要求元プロジェクトが HTML を全面的に書き換える負担を避けるため。`no` は課題番号のクラスと衝突するため `part` に改名し、表の見出しは `data-columns` 属性（必須。無いとエラーで止まる）から取る。詳細は[タグ対応仕様の決着 10](../10_plan/html2md-tag-spec.md)。`html-class-rules.html`・`TOOLS-USAGE.html` は反映済み。要求元への周知と、`~/.claude/CLAUDE.md` のクラス名一覧への反映は**利用者の判断を待つ**。

❌ **不具合** 要求元プロジェクトから ai-chat-lite（#699）で報告。<strong>ttl のリンクだけ href が `.html` のまま置き換わらなかった。</strong>実装が `href` を自前で `"[text](href)"` に組み立てており、`.md` 置換・他ファイルのアンカー張り替えを行う共通経路（`ConvertLinkTarget` ／ `inline.Convert`）を素通りしていたのが原因。✅ **済** 同日に修正。ttl の生の中身を合成 `<a>` に包んで `inline.Convert` に通す形にし、他のリンクと同じ経路を通るようにした（exe・ps1 両方）。テストケースに実在するリンク先ファイルを足し、`.md` 置換が効くことを確認する回帰を追加。
