2026-09-12、`ai-chat-lite-reviewer` から指摘（html2md ルーム #793）。共通ルール「root の README.html と資料の html は相互リンクする」に**戻るリンクをアイコンだけにする規定**が入ったが、**html2md がそれを Markdown に落とせない。**

### 実測

指摘を受けて `tmp/` に見本を作り、変換した。**指摘のとおりだった。**

```html
<a class="backlink" href="../"><svg width="16" height="16" …><path d="M8 1 1 7h2v7h4v-4h2v4h4V7h2z"/></svg></a>
```

```markdown
[](../)
[](01-前.html) [](03-次.html) [](README.md)
```

<strong>リンクテキストが空になり、GitHub では何も表示されない。</strong>SVG の `images/` への切り出しも起きない（リンクの中の SVG は対象外の扱い）。

### あわせて確認した点

指摘元から「`docs/` 配下の前へ・次へ・目次バッジは置き換わっているか」と問われたので調べた。**置き換わっていない。**`<<` ・ `>>` ・ `^^` への置換は**ソース全体で 1 件も実装されていない**（共通ルール「資料間のリンク」には規定がある）。

> [!IMPORTANT]
> <strong>`.backlink` だけの問題ではない。</strong>アイコンだけのリンク全般が対象で、`docs/` を持つプロジェクトでは前へ・次へ・目次の 3 つが同じように空になる。

### 決めたこと

**何に置き換えるかは共通ルールで決まっていた**（前へ `<<` ／ 次へ `>>` ／ 目次 `^^`）。決めたのは<strong>どのアイコンかをどう判別するか。</strong>次の順で手がかりを探す。

| 順 | 手がかり | 置き換え |
|---:|---|---|
| 1 | `<a aria-label>` | 語が表にあれば記号。**表に無い語はその語をそのまま文字にする** |
| 2 | `<a title>` |  |
| 3 | `svg` の中の `<title>` |  |
| 4 | `<a class="backlink">` | `^^` |
| 5 | どれも無い | **空のまま。検査で指摘する** |

> [!IMPORTANT]
> <strong>SVG の形（`path` の `d`）では判別しない。</strong>共通ルールはアイコンの意味（`⌂` ・ `‹` ・ `›`）だけを定めており、`d` の実値に規定が無い。辞書を持っても当たる保証が無く、外れたときに**静かに空のまま通る**。推測で当てるより、指摘して書き手に気づかせる方を採った。

### 途中で見つかったもの

<strong>`<<` が消えていた。</strong>最終段の汎用タグ除去（`<[^>]+>`）が `<<](b.md) [>` をタグ 1 個と誤認して飲み込み、`[>](b.md)` だけが残る。

<strong>既存の `<br>` と同じセンチネル退避方式で直した。</strong>制御文字（15）に置いてタグ除去を通過させ、通過後に `<<` へ戻す。汎用タグ除去の正規表現を厳しくする方が根本的だが、**全ケースに影響が及ぶ**ため、影響が閉じる方を採った。

**「HTML に無い文言」検査も 2 点直した。**(1) 記号 `<<` ・ `>>` ・ `^^` を両側から落とす（共通ルールが認めた代替なので付け足しではない）。(2) `aria-label` を**元の位置に埋めてから**突き合わせる。末尾にまとめて足す作りだったため、`…にする: 付録` のように地の文と繋がった行が一致しなかった。

### テスト

ケース `icon-link` を新設。**期待値（終了コードと ★ 行）を手で書いてから実装した**ので、実装の出力に引きずられていない。手で書いた `expected.txt` と実装の出力は一致した。

✅ **済** html2md 16 ケース ・ convert-encoding 140 件 ・ text 55 件すべて成功。
