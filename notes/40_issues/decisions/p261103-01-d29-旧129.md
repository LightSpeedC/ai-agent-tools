## 案

- A: 決定済み (2026-11-05、利用者の判断): A (恒久) : 画像は 2 枚 (<名前>-light.png ・ <名前>-dark.png) にし、Markdown には URL の末尾の印 (#gh-light-mode-only ・ #gh-dark-mode-only) を付けた 2 行で書く。生成した HTML では、<picture> と prefers-color-scheme に変換する (推す理由: GitHub は、この印で明暗を切り替えられる。生成した HTML でも、同じ書き方から明暗を切り替えられる)
- B: B (恒久) : 明暗を分けず、1 枚で足りる絵にする (背景を白で作る) (推す理由: 書き方が単純で、検査も要らない。ただし、ダークモードで白い箱が浮き、画面の見え方を確かめる課題には向かない)
