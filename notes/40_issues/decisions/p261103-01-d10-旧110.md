## 案

- A: <id>-<件名>.md。件名は立てるときに決める短いスラッグで、あとから変えない (推す理由: 一覧 ・ git log --stat で中身が分かる。題を直しても名前が動かない。重複は、予約の mkdir と issue check の 2 段で止める)
- B: <id>.md (件名なし) (推す理由: 重複の排他がファイルの作成だけで済み、単純。ただし、一覧で ID しか見えず、中身は開くまで分からない)
