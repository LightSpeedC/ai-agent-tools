## 案

- A: 常駐は作らない。 起動は短命の node (約 50 ms で終わる) に任せ、窓の番人は cmd のループにする。長く生きる node ・ bun は 0 本。エージェントの数だけ node ・ bun を起動すると、メモリと不要なプロセスが無駄になるため (実測: node の待機は約 18〜49 MB、bun は約 16〜55 MB、cmd は約 8 MB)。 88-A (窓ごとに node の番人) は、この理由で改めた (2026-11-01、利用者の判断)
