## 案

- A: done に一本化 (値は日付)。closed は done に寄せる
- B: closed (日付) と done を両方残す
- C: closed に一本化 (値は日付)
- D: closed に一本化し、値を日時 YYYY-MM-DD HH:mm (JST) にする。done は作らない。日付だけの既存値は有効
- E: done に一本化し、値を日時にする。closed は done に寄せる

利用者は当初 287-A を選んだが、closed は日時にしたかったのを思い出し、287-D に変えた。検索は closed: の前方一致で 1 日分を探せ、日別の集計は頭 10 文字で数える。develop に closed が先にあり、file-manager が使っているため、名前は closed を残す。
