## 案

- A: 決定済み (2026-11-05、利用者の判断): A (恒久) : 生成だけの issue render と、生成して開く issue view の 2 つ。view は render を呼んで開く。更新の操作の最後の自動の作り直しは render (推す理由: 名前が、やることを表す。AI は render だけを使えば、窓が開かず、作業中の画面とフォーカスを奪わない)
- B: B (恒久) : issue view 1 つで、--no-open を付けると生成だけ (推す理由: コマンドが 1 つ。ただし、AI が --no-open を付け忘れると、窓が開く)
- C: C (恒久) : issue view 1 つで、既定は生成だけ。--open で開く (推す理由: 付け忘れても窓は開かない。ただし、人が issue view と打っても何も開かず、名前と動きが食い違う)
