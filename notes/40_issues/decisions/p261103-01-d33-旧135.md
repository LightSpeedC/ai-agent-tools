## 案

- A: 決定済み (2026-11-05、利用者の判断): A (恒久) : issue render --standalone が、画像を data: URI で埋め込み、旧 HTML と Markdown へのリンクを外した、自己完結した HTML を作る。--out <ファイル> で出力先を指し、渡すときは tmp/ へ出して、送ったら消す (推す理由: 相手の端末で、そのまま見られる。tmp/ に作って消す流れは、共通ルール「一時ファイルの削除」と合う)
- B: B (恒久) : --standalone を持たず、_issues.html をそのまま渡す (推す理由: 実装が要らない。ただし、受け手の端末で、画像と旧 HTML へのリンクが切れる)
