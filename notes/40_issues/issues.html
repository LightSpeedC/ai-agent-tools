済i260830-02ブロックとして扱っていないタグの構造が失われる

次のタグは BlockTags に無いため、中身が地の文として 1 つに連結される。テキストは消えないが構造は失われる。

タグいまの出力本来あるべき形

済2026-09-01 にテキストを落とさない対処を入れた。hr を除くすべてを走査の対象に加え、dt dd summary も個別に挙げて項目ごとの段落にした。address と caption も同時に対応した。

済2026-09-05 に構造の落とし先を 3 つとも決めて実装した。dl は箇条書き（dd は 4 字下げ）、details はタグのまま出す、hr は ---。決着はタグ対応仕様の決着 9 にある。

済i260830-04意味を持つインラインタグが平文になる

del ins sup sub mark kbd abbr small q cite time はタグが消えて中身のテキストだけが残る。取り消し線や上付きの区別は Markdown に出ない。

GitHub は ~~取り消し線~~ を解釈するので del は記法にできる。sup sub kbd は HTML のまま残す手もある。どこまで対応するかを決める。

済2026-09-01 に対処。del は ~~、GitHub で生き残るタグ（ins sup sub mark kbd q）はタグのまま残す。~~ も ** と同じ前後判定を受けるため、強調と同じセンチネル方式に載せた。成立しない位置では <del> で出る。

どのタグが残るかは実測で決めた。11 個すべてタグで出す実装にしたあと api.github.com/markdown へ投げたところ、abbr small cite time の 4 個は除去された（中身のテキストは残る）。表示に効かないため平文に落とすことにした。

この対応で退避の仕組みに潜んでいた欠陥が表面化した。キーの両端が同じ制御文字だったため、2<sup>10</sup> のように数字が隣接すると偽のキーができ、別の退避内容に置き換わっていた。両端を別の文字にして直した。

済i260830-10SVG 切り出し時に CSS 変数を解決する

デザインルールは stop-color="var(--accent)" の書き方を前提にしているが、SVG を単体ファイルに切り出すと変数が解決されず色が失われる。

<section class="ch03">
	<svg><linearGradient id="g-03-1a">
		<stop stop-color="var(--accent)"/>    ← .ch03 の定義が要る
	</linearGradient></svg>
</section>

<style> から .chNN { --accent: … } を読み、切り出す svg の祖先 section のクラスと突き合わせれば静的に解決できる。@media と JS による上書きは対象外とする。

ルールに従って書いた HTML ほどこの問題を踏む。この html2md 自身の図はリテラルの hsl() で書いていたため表面化していなかった。

済2026-09-02 に対処。上の方針どおり実装した。定義も既定値も無いものは書き換えずに残す（消すと図が壊れるより、そのままのほうが気づける）。@media の中はブロックごと落としてから読む。

フォールバックの取り出しは括弧を数えている。var(--x, hsl(280,78%,25%)) のように既定値の中に括弧が入ると [^)]* では途中で切れて壊れる。

あわせて、テストが .md しか比べていなかったのを直し、切り出した .svg も exe と ps1 で突き合わせるようにした。既存 6 プロジェクトの SVG に var( を含むものは無く、影響は出ていなかった。
