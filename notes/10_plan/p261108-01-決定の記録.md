## 2. ファイルの形

### 置き場と名前

- **置き場は `notes/40_issues/decisions/`**。状態のフォルダは持たない (決定は、決めた時点で確定している。覆すときは、新しい決定を立てて `replaces` で指す)
- **名前は `<id>-<件名>.md`**。件名の文字と長さは、課題と同じ決まり
- **id は、親の番号 + `-d` + 連番** (152-A)。連番は 10 進数で 1 から数え、桁をそろえない (`p261103-01-d96`)。**親は、課題 (`i`) ・ 計画 (`p`) ・ 調査 (`r`) の番号**

### 中身

```markdown
---
schema: 1
id: p261108-01-d1
title: 進める順
parent: p261108-01
decided: 2026-11-08
chosen: A
refs: p261106-01
legacy_ids: :ai-agent-tools:171-A
---

## 案

- A: フェーズ 5 を先に作る (恒久)。索引にも移行にも頼らないため
- B: 計画どおり、フェーズ 1 から順に進める (恒久)
```

| キー | 必須 | 値 |
|---|---|---|
| `schema` | 必須 | `1` |
| `id` | 必須 | ファイル名の先頭と同じ |
| `title` | 必須 | 問い (1 行) |
| `parent` | 必須 | 親の番号。id の `-d` より前と同じ |
| `decided` | 必須 | 決めた日 (実在する yyyy-mm-dd) |
| `chosen` | 必須 | 選んだ案の英大文字 1 字。本文の案の行に、その字がある |
| `refs` | 任意 | 参照する課題 ・ 計画 ・ 調査の番号 (カンマ区切り。課題と同じ形) |
| `replaces` | 任意 | この決定が置き換えた決定の id (カンマ区切り) |
| `legacy_ids` | 任意 | 旧番号。`:プロジェクト名:旧番号` をカンマで区切る (153-A) |

- **案の行は `- X: 文`** (X は英大文字 1 字)。本文のどこに置いてもよい。`## 案` の見出しは、`issue decide new` が書く形で、検査はしない
- 文字コードは課題と同じく、UTF-8 の BOM 無し ・ LF

## 3. 操作と検査

### 操作

```text
issue decide new --parent <番号> --title <問い> --option <文> [--option <文> …] --chosen <A|B|…>
                 [--slug <件名>] [--refs <番号,…>] [--replaces <id,…>] [--legacy <旧番号,…>] [--body <本文>] [--root <dir>] [--json]
issue decide list [--parent <番号>] [--root <dir>] [--json]
issue decide show <id> [--root <dir>] [--json]
```

- **`new`**: `--option` を書いた順に A ・ B ・ C … と振り、本文の `## 案` に書く。`--chosen` は、振った字のどれか。連番は、親の決定の最大 + 1。**同じ PC で同時に足しても重ならないよう、課題と同じ予約 (`_lock/<id>/`) を使う**。決めた日は JST の今日 (試験は `ISSUE_TEST_TODAY`)。何かを書く前に、引数をすべて確かめる
- **`list`**: id の順 (親の番号 → 連番の数の順)。`--parent` で絞る
- **`show`**: 1 件を出す。`--json` では、メタ情報と案の一覧
- 課題と同じく、ファイルを作るだけで commit しない。出力に絶対パスを出さない

### 検査 (`issue check` に足す)

- **エラー**: 名前の形 (`name`) ・ 必須キーの不足と値の形 (`key` ・ `value`) ・ id と名前の先頭の食い違い ・ `parent` と id の食い違い ・ `chosen` の字の案が本文に無い (`chosen`) ・ 同じ id のファイルが複数 (`duplicate`。別の PC で同じ親へ同時に足したとき) ・ BOM と CR (`encoding`) ・ `decisions/` の下のフォルダに置いた `.md` (`place`)
- **警告**: 親が見つからない ・ `refs` と `replaces` の参照先が見つからない (`refs`)。別プロジェクトの参照は検査しない ・ キーの順 ・ 知らないキー
- 集計の行に、決定の件数を足す。`decisions/` が無いプロジェクトは、これまでと同じ (警告にしない)
